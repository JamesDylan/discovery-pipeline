# 101-prototype-handoff

Terminal step, optional and discrete. Converts `99-vision-synthesis/output/12-month-vision.md`
into prototype briefs for the tool named in `_shared/prototype-target.md`. Read `CONTEXT.md`.

Run only after `99`. Use this when a surface needs more than one run's territory to make sense.
A surface that sits inside a single run belongs in that run's `10_prototype-handoff` instead.
