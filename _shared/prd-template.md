# Release PRD template

The shape `release-prd/04_prd` writes to. One home for the house format: change sections here, never
in the stage contract.

> **STATUS: STARTER.** A generic shape. Replace it with your organisation's PRD format.

## Sections

1. **Title block** — release name, owners, status, date, version.
2. **Summary** — 3 sentences: the problem, the slice, the outcome.
3. **Problem** — from `problem.md`: statement, evidence, who is affected.
4. **Outcome** — the metric, current value, target, and how it will be measured.
5. **Scope** — from `scope.md`: in, out, and the trade-off sentence.
6. **Features** — one line and one slug per feature. Link to each feature PRD run when it exists.
   Do not specify features here.
7. **Risks and dependencies** — each with an owner.
8. **Open questions** — each with an owner and a date.

## Length

Aim for 2 pages. If it grows past 4, detail is leaking in from the feature PRDs.
